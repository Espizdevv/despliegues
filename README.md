# Ejercicio: encuentra el bug y despliega la solución

## Contexto

Esta es una landing page sencilla (HTML + CSS) para EIG Campus. Tiene un bug visual introducido a propósito.

## Tu tarea

1. Haz un fork o clona este repositorio.
2. Abre `index.html` en tu navegador (puedes usar Live Server, por ejemplo).
3. Observa la página: hay algo que no se ve bien. Pista: fíjate en el botón "Empezar ahora".
4. Usa las herramientas de desarrollador del navegador (clic derecho → Inspeccionar → pestaña *Styles*) para localizar la regla CSS responsable del bug.
5. Corrige `styles.css`.
6. Haz commit de tu solución con un mensaje descriptivo.
7. Despliega la versión corregida (por ejemplo con GitHub Pages: *Settings → Pages → Deploy from branch*) y comparte el enlace público.

## Criterios de evaluación

- El bug ha sido identificado correctamente.
- La corrección en `styles.css` soluciona el problema sin romper el resto del diseño.
- El historial de commits es claro (al menos un commit describiendo el fix).
- La web queda desplegada y accesible públicamente.
